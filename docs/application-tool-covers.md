# 应用工具封面

生成方式：内置 image_gen。25 张独立生成的场景图片，已转为 960px 宽 WebP（质量 82），用于应用工具目录。

## 使用与管理

- 默认图片：`public/tool-covers/<tool-id>.webp`。
- 管理入口：个人中心 → 门户内容管理 → 工具目录（平台管理员）。
- 支持上传、更换 URL、恢复默认图片、调整排序、优先推荐与隐藏。
- 每类先取优先推荐工具，未满 3 个时按排序补齐；其他工具保留在更多工具中。
- 新增的工具沿用 Agent 任务入口：进入工作台带入工具名称，由用户补充任务后执行。
